# Wayward House — hub site

Astro static build deployed to Cloudflare Pages. Hub for essays, the System Signals newsletter, and a Library of long-form books that live as separate Quarto deploys under `wayward.house/<slug>/`.

## Stack

- **Astro 5** (`output: 'static'`) — content collections, MDX, image optimization
- **Cloudflare Pages** + **Wrangler** for deploy
- **Pagefind** for client-side search (built into the navbar; press `/` or click Search)
- **Satori + resvg** for build-time OG image generation
- **`@astrojs/cloudflare`** adapter is included so you can opt into hybrid SSR (e.g. dynamic OG endpoints) without re-tooling

## Hero variants

The home page has three hero variants — `cinematic` (default), `editorial`, `document`. Switch via `?hero=editorial` or use the in-page switcher (visible on localhost or with `?preview=1`).

## Image manifest + `<WhImage>`

`src/content/images.ts` is the single source of truth for every photograph. To add an image:

1. Add an entry to `library` with id, pillar, slug, coords, author, mood, default treatment, aspect.
2. Either keep `unsplash:` for hotlinking during design, or remove it and drop the file at `public/images/<pillar-lowercase>/<slug>.jpg`.
3. Reference it anywhere with `<WhImage id="geo-02" treatment="duotone" ratio="21/9" />`.

Treatments are CSS-only: `raw`, `warm` (graded + grain), `duotone` (grayscale + multiply accent), `caption-bar` (light filter + amber coords bar + filename + WH mark).

## Books — routing

Each book is its own Quarto project deployed independently as a Cloudflare Pages project. The hub apex (`wayward.house`) rewrites `/<slug>/*` to the book's deploy via `public/_redirects`. Until a book is live, the hub serves its own stub front page (`src/pages/[book]/index.astro`) and a chapter sample (`src/pages/[book]/[chapter].astro`) so you can iterate on chrome without spinning up Quarto.

To wire up a book:

1. Deploy the Quarto project to its own Cloudflare Pages project (e.g. `computational-geography.pages.dev`).
2. Uncomment the matching line in `public/_redirects` and re-deploy this project.
3. The hub's `[book]` stub becomes effectively unreachable.

## Search

Pagefind is generated by `pagefind --site dist` in `npm run build`. The trigger lives in the header; the UI is loaded lazily on first activation. Press `/` from anywhere to open it.

## OG images

`scripts/generate-og.mjs` runs after `astro build` (see `postbuild:og` in package.json). It walks `src/content/essays/`, renders an SVG per essay with Satori, rasterizes with resvg, and writes to `dist/og/essays/<slug>.png`. Layout.astro emits a canonical `og:image` URL pointing at that path.

> Drop the four required TTFs into `public/fonts/`:
> `BarlowCondensed-Regular.ttf`, `BarlowCondensed-Bold.ttf`, `IBMPlexMono-Regular.ttf`. The script no-ops with a warning if they're missing.

## Deploy

### Local
```bash
npm install
npm run dev          # localhost:4321
```

### Cloudflare
```bash
npm run build
wrangler pages deploy ./dist --project-name=wayward-house
```

### CI
`.github/workflows/deploy.yml` runs on every push to `main`. Required secrets: `CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID`, `CF_ANALYTICS_TOKEN` (optional).

## What you fill in

- Replace placeholder Cloudflare Web Analytics token in `wrangler.toml`
- Vendor real photographs into `public/images/<pillar>/` (or stay on Unsplash hotlinks for now — the manifest supports both)
- Set up the Buttondown form ID in `src/pages/signals/index.astro` (currently `wayward-house`)
- Once each book has a deploy URL, uncomment its `_redirects` line
